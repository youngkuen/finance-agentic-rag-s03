# ADR-002. 인제스천에 LangGraph 를 쓰되, 문서당 LLM 루프는 두지 않는다

- 상태: 채택
- 날짜: 2026-10-02
- 관련: ADR-001, `src/finrag/ingestion/graph.py`

## 맥락

2회차까지 파싱·검사·청킹은 돌아갔지만 셋이 따로 놀았다. 문서 한 건이 어디서 걸렸는지
알려면 로그를 뒤져야 했고, 깨진 PDF 를 다른 파서로 다시 뽑는 복구 경로는 if 문 속에
숨어 있었다. 51건 중 2건은 형식이 지원되지 않고 1건은 어떤 파서로도 쓸 페이지가 안 나온다.
이 3건을 조용히 버리면 "검색이 못 찾은 것"과 "애초에 안 들어간 것"을 구분할 수 없다.

| 무엇 | 값 | 출처 |
|---|---|---|
| 처리 문서 → 청크 | 49건 → 3,695개 | `data/ingest_report.json` |
| 게이트 판정 | pass 40 · reparse 5 · ocr 2 · fail 2 | `data/ingest_report.json` |
| 사람 검토 큐 | 3건: hwp 1 · hwpx 1 (형식 미지원), `knia_4000` 1 (쓸 페이지 0) | `failed[].reasons` |
| 정상 경로 LLM 호출 | 0회 (`llm_repaired: []`) | `data/ingest_report.json` |
| 첫 검색 성능 | Recall@5 0.775 · MRR 0.555 | `results/baseline.json` |

큐의 3건은 원인이 둘로 갈린다. 형식 때문에 못 읽은 것(변환기 도입)과 글자가 깨진
것(OCR·LLM 복구)은 대응이 다르다. 게이트가 office/missing 을 검사기에 넣지 않는 이유다.

## 대안

| # | 대안 | 왜 안 골랐나 |
|---|---|---|
| A | 문서마다 LLM 에게 읽혀서 정리시킨다 | 비용·지연이 문서 수에 비례하고 같은 입력에 다른 출력이 나온다. 무엇보다 모델이 약관 조항을 그럴듯하게 지어내면 그게 근거로 인용된다 |
| B | if 문으로 직접 짠다 | 분기가 4개에서 멈추지 않는다. 경로 추적은 로그 파싱, 재실행은 매번 처음부터. 4회차에 검색이 얹히면 더 복잡해진다 |
| C | **LangGraph 로 제어흐름만, LLM 은 실패 브랜치에만** | **← 골랐다.** 경로가 상태로 남아 리포트가 공짜, 조건부 엣지로 분기가 선언적, 체크포인트로 재실행이 멱등 |

## 결정

> 인제스천은 결정적 파이프라인(classify → parse → gate → chunk)으로 세우고, LLM 은
> `llm_repair` 한 노드에만 둔다. 그 노드는 재추출 뒤에도 쓸 페이지가 **0개일 때만** 부른다.

## 근거 지표

| 지표 | 전 (2회차) | 후 (3회차) |
|---|---|---|
| 문서 경로 추적 | 로그 수동 확인 | `ingest_report.json` 자동 생성 |
| 게이트 판정 종류 | pass/fail 2종 | pass·reparse·ocr·fail 4종 |
| Recall@5 / MRR | 측정하지 않았다 | 0.775 / 0.555 |

재현 명령: `make ingest && make index && make baseline && make check-s03`

## 대가

| 잃은 것 | 받아들일 만한 이유 |
|---|---|
| 의존성 1개 (langgraph) | 분기가 4개를 넘는 순간 if 문보다 읽기 쉽다 |
| 깨진 페이지 5건을 지우지 않고 색인 | 지우면 아무것도 못 찾지만 두면 임베딩은 찾는다. `meta.degraded_pages` 로 분리 가능 |
| hwp/hwpx 2건은 손도 못 댐 | 변환기 도입은 별도 결정. 큐에 이유와 함께 남기면 충분 |

## 되돌릴 조건

- [ ] Recall@5 가 0.60 아래로 내려가면 (파서 품질이 원인인지부터 본다)
- [ ] 사람 검토 큐가 전체의 10% 를 넘으면 (지금 3/49 = 6.1%)
- [ ] 문서 수가 500건을 넘으면 (순차 6분 → 1시간. 병렬 실행 검토)
- [ ] `llm_repair` 호출이 전체의 5% 를 넘으면 — 그때도 문서당 LLM 이 아니라 파서 교체를 먼저 본다

되돌리는 비용: `graph.py` 한 파일(약 40줄). 인덱스 재생성은 스냅샷 있으면 14초, 없으면 25분.

## 결과

49건이 네 갈래로 갈려 46건 색인, 3건은 이유와 함께 큐에 남았다. Recall@5 0.775 지만
유형별로는 계산형 0.600 · 미답변형 0.000 으로 평균이 가리는 구멍이 있다. 4회차의 검색
개선이 이 구멍을 메우는지 같은 지표로 다시 본다.
